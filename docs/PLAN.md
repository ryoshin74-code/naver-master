## 1. 목표

유튜브 공구 영상 송출 → **D+1에 네이버 카페·블로그 자동 포스팅**(시선 끄는 제목 + 영상 캡처 정리 + 유튜브 링크 + 구매 링크) → **댓글 자동 응대** → **매일 아침 카톡 보고**(댓글/답글 내역·반응·방문자 수)까지, 사용자 관여 없이 도는 시스템.

**성공 기준**
- 영상 송출 후 사람 손 없이 25시간 이내에 카페·블로그 포스팅 완료율 95% 이상
- 호응성 댓글 4시간 이내 답글, 문의성·민감 댓글 100% HOLD 후 아침 보고
- 매일(주말 포함) 오전 10시 카톡 보고 무결손
- 네이버 계정 제재 0건

## 4. 파이프라인 상세

### P1 감지 (watcher) — 시스템 단독
- 매시 정각 채널 RSS 폴링 → 신규 video_id 발견 시 DB `videos`에 등록, `publish_at = 송출시각 + 24h` 예약.
- 영상 설명란에서 구매 링크 추출 (설정 `purchase_link_source`). 링크가 없으면 즉시 카톡 경고 (이 건만 HOLD).

### P2 분석 (analyzer) — 대장1 + 코어
- yt-dlp(쿠키+POT 플러그인)로 영상·자막 다운로드 → ffmpeg 장면전환 기반 후보 프레임 30~60장 추출.
- Claude API(비전)에 프레임+자막 투입 → 산출(JSON): 상품명, 핵심 셀링포인트 3~5개, 가격·구성·공구기간, 타임라인 요약, **포스팅용 베스트 캡처 6~10장 선정**(상품 클로즈업·사용 장면·가격 화면 우선).

### P3 생성 (writer) — 코어
- 블로그용: 후킹 제목 후보 5개 + 본문(서론-포인트별 캡처 배치-가격/기간-구매링크-영상링크-광고고지) 1,200자 내외.
- 카페용: 같은 소재를 카페 톤(커뮤니티 말투)으로 재작성 600자 내외. **블로그와 문장이 겹치지 않게** (동일문 양산 = 저품질 트리거).
- 제목 선정: 검수 LLM이 후보 5개를 낚시성·정확성 기준으로 채점해 1위 채택.

### P4 검수 (approver) — 코어
- `APPROVAL_POLICY.md`의 2단 게이트. PASS 시 승인 토큰 발급 → 게시 지시서 생성.

### P5 게시 (poster) — 대장3(블로그)·대장4(카페)·대장6(검증)
- 블로그: naver-main 프로필로 스마트에디터 접근, 본문은 클립보드 경유 입력(타이핑 탐지 회피), 이미지 업로드, 게시 시각은 윈도우 내 지터 적용.
- 카페: 1차 = 카페 오픈API 호출(코어가 직접). API 권한 발급 불가 판명 시 = 대장4 컴퓨터유즈.
- 게시 +10분, 대장6이 비로그인 브라우저로 실제 노출·링크 정상 여부 확인 → 보고서.

### P6 응대 (responder) — 대장3·4 순차
- 09~22시 2시간 주기로 새 댓글 수집 → 분류(호응성/문의성/민감성).
- **호응성 댓글만** 코어가 답글 생성 → P4 게이트(답글 룰) → 게시.
- **문의성**(새 정보를 요구하는 질문)과 **민감성**(클레임·환불·분쟁)은 자동 답변하지 않고 답글 초안만 만들어 HOLD, 아침 보고에 정리 첨부. (운영 후 부담되면 "본문에 이미 있는 정보 재안내"형 문의만 자동으로 풀 수 있음 — 총사령관 승인 필요)

### P7 보고 (reporter) — 코어
- 09:30 대장5가 크리에이터 어드바이저에서 전일 방문자·조회수 수집 → DB.
- **매일(주말 포함) 10:00** 카톡 발송. 200자 제한 대응: **요약 1건 + 상세 분할 2~3건** (전문은 `ops/reports/daily/YYYY-MM-DD.md` 보존).
  - 내용: 신규 포스팅(제목+URL) / 새 댓글 n건 요약·답글 내용 / 반응(공감·조회) / 방문자 수(블로그·카페) / HOLD 목록과 사유 / 시스템 상태(토큰 만료 임박, blocked 발생 등).

## 7. 로드맵

| Phase | 내용 | 완료 기준 | 사용자 관여 |
|---|---|---|---|
| **0** | 준비·검증: 키 발급, naver-main 프로필 수동 로그인, 카페 API 권한 실확인, 카톡 발송 테스트, yt-dlp 동작 확인 | 모든 외부 연결 스모크 테스트 통과 | 계정·키 준비 (아래 체크리스트) |
| **1** | 반자동: P1→P2→P3→P4까지 자동. 완성 초안을 카톡으로 발송, **게시는 사용자가 수동** | 영상 1건이 초안까지 무인 도달 | 초안 품질 피드백 (톤 가이드 보정) |
| **2** | 블로그 자동 게시 + 검증반 가동 + 아침 보고 v1 | 블로그 3건 연속 무인 게시·검증 통과 | 모니터링만 |
| **3** | 카페 게시 + 댓글 자동 응대 | 댓글 응대 1주 무사고 | 모니터링만 |
| **4** | 통계 수집 + 보고 완성 + 2주 안정화 → **완전 무인 운영** | 2주간 수동 개입 0회 (로그인 갱신 제외) | 아침 보고 수신만 |

Phase 1을 거치는 이유: 자동승인 게이트가 사용자 기준과 일치하는지 **실데이터로 보정**한 뒤에 게시 권한을 넘겨야 R1·R2 위험이 통제된다.
