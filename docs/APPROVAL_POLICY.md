# 자동승인 정책 — 사용자 대리 승인 시스템

> 사용자가 건별 승인을 할 수 없으므로, 이 정책에 따라 시스템이 사용자를 **대리하여** 게시를 승인한다.
> 게시(새 글·답글)는 예외 없이 이 게이트를 통과해야 하며, 통과 시 승인 토큰(`APPROVAL-{id}-PASS`)이 발급된다.

## 판정 체계: 2단 게이트

### 1단 — 룰 체크 (기계 검사, 전부 통과해야 2단 진행)

새 포스팅:
- [ ] 제목 8~40자, 금칙어 없음, 낚시성 허위(영상에 없는 내용 단정) 없음
- [ ] 본문 길이 800자 이상 (블로그) / 400자 이상 (카페)
- [ ] **유튜브 영상 링크 정확히 1개** — 대상 영상 ID와 일치
- [ ] **구매 페이지 링크 1개 이상** — HTTP 200 응답 확인
- [ ] 이미지(영상 캡처) 3장 이상 첨부
- [ ] 본문 내 가격·수량·기간 표기가 P2 분석 결과(영상에서 추출한 값)와 일치
- [ ] 광고·대가성 고지 문구 포함 (표시광고법 대응 문구, config에서 관리)
- [ ] 금칙 표현 없음: 의료적 효능 단정, "최저가 보장" 등 검증 불가 단정, 타사 비방
- [ ] 일일 게시 한도 이내 (기본: 블로그 2건/일, 카페 2건/일), 직전 게시와 90분 이상 간격

답글:
- [ ] 2~3문장 이내, 존댓말, 이모지 0~1개
- [ ] 가격·재고·배송 일정을 **새로 단정하지 않음** (영상·본문에 이미 있는 정보만 재안내)
- [ ] 민감 분류(클레임·환불·분쟁·법적 언급)가 아님 → 민감이면 즉시 HOLD

### 2단 — LLM 검수 (작성자와 분리된 검수 프롬프트)

별도 컨텍스트의 검수 LLM이 다음 4개 축을 1~5점 채점, **모든 축 4점 이상**이어야 PASS:
1. **사실 일치성**: 본문 주장 전부가 영상 분석 결과로 뒷받침되는가
2. **품질**: 사람이 쓴 것처럼 자연스럽고, 캡처·문단 구성이 읽기 좋은가
3. **안전성**: 과장광고·허위·권리침해 소지가 없는가
4. **브랜드 톤**: config의 톤 가이드(사용자 말투 샘플)와 일치하는가

## 판정 결과

| 판정 | 조건 | 처리 |
|---|---|---|
| **PASS** | 1단 전부 + 2단 전축 4점↑ | 승인 토큰 발급 → 게시 큐 투입 |
| **FAIL** | 1단 탈락 or 2단 3점 이하 축 존재 | 탈락 사유를 피드백으로 재생성 (최대 2회) → 그래도 FAIL이면 HOLD 전환 |
| **HOLD** | 재생성 소진 / 민감 댓글 / 판단 불가 | 게시하지 않고 아침 보고에 사유와 초안 첨부 → 사용자가 결정 |

## 안전 한도 (하드 리밋 — 어떤 로직도 초과 불가)

| 항목 | 한도 |
|---|---|
| 새 포스팅 | 블로그 2건/일, 카페 2건/일 |
| 답글 | 합산 30건/일, 같은 글에 시간당 5건 이하 |
| 게시 시간대 | 09:00~22:00 KST만 |
| 연속 실패 | 같은 유형 3회 연속 blocked/failed 시 해당 유형 자동 일시정지 + 보고 |

## 비상정지

- `ops/state/PAUSE` 파일 생성 = 전체 게시·답글 즉시 중단 (사용자 또는 지휘관 누구나 발동 가능).
- 네이버로부터 경고/캡차/이용제한 신호 감지 시 시스템이 스스로 PAUSE를 발동하고 즉시 카톡 알림.

## 기록 의무

모든 판정(PASS/FAIL/HOLD)은 점수·사유와 함께 DB `approvals` 테이블에 남긴다.
아침 보고에는 전일 판정 통계(승인 n / 보류 n / 거절 n)가 포함된다.
